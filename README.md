# Alzheimer's Disease Risk Prediction System

An enterprise-ready, production-grade Machine Learning classification system for the early detection and risk assessment of Alzheimer's Disease. This application features a robust FastAPI backend leveraging standardized clinical parameter inputs, strict request-response data validation via Pydantic, a multi-model training/evaluation ML lifecycle, and a glassmorphism client UI with interactive analytics dashboards.

---

## 1. Project Overview & Problem Statement

### Problem Statement
Alzheimer's Disease is a progressive, neurodegenerative disorder that accounts for 60-80% of dementia cases. Early diagnosis is highly critical for clinical trials, therapeutic interventions, and personalized patient care planning. However, diagnosing Alzheimer's early is challenging due to the complex, non-linear correlations between cognitive, biometric, and demographic patient markers.

### Solution
This project provides an automated clinical screening solution. By utilizing clinical features (cognitive scores, biometric indicators, and subjective symptoms), the system employs a trained Random Forest Classifier to output immediate risk classification labels (Low Risk / High Risk) and exact probability confidence percentages. The logic is encapsulated in a professional, modular backend ready for cloud scaling.

## 5. Machine Learning Ingestion & Training Pipeline

### Dataset
The training dataset [alzheimers_disease_data.csv](file:///C:/Users/spand/college/GENETIC_ML/data/alzheimers_disease_data.csv) contains 2,149 patient records. Each record spans 32 clinical parameters. The target variable is `Diagnosis` (Binary classification: `0` = Low Risk, `1` = High Risk).

### Preprocessing & Feature Selection
1. **Cleaning**: Identifier attributes (`PatientID`, `DoctorInCharge`) are discarded.
2. **Imputation**: Missing features are imputed with the mean of the column using `SimpleImputer`.
3. **Feature Selection**: Combines Random Forest Feature Importances (Top 5) and ANOVA F-value test `SelectKBest` (Top 5) to isolate the most predictive feature subset:
   - `MemoryComplaints`, `FunctionalAssessment`, `MMSE`, `ADL`, `BehavioralProblems`
4. **Standardisation**: Numerical values are standardized to a uniform scale (mean = 0, variance = 1) using `StandardScaler`.

### Model Training & Selection
The pipeline trains 4 candidate estimators: Random Forest, K-Nearest Neighbors, Decision Tree, and Logistic Regression. Based on sorted cross-validation scores:
- **Random Forest** achieved the best performance: **94.65% Accuracy**, **92.36% F1-score**, and **91.45% Recall**.
- The model estimator and its standardization preprocessor are serialized to `models/rf_alzheimers_model.pkl` and `models/scaler.pkl` respectively.

For a detailed analysis of the pipeline, see [ML_PIPELINE.md](file:///C:/Users/spand/college/GENETIC_ML/docs/ML_PIPELINE.md) and [MODEL_EVALUATION.md](file:///C:/Users/spand/college/GENETIC_ML/docs/MODEL_EVALUATION.md).

## 6. API Endpoint Overview (FastAPI)

### `GET /health`
Verifies that the server and loaded model objects are healthy.
* **Response**: `{"status": "healthy"}`

### `GET /metrics`
Serves comparative evaluations, ROC curves, feature importances, and matrices in JSON.

### `POST /predict`
Processes clinical features and outputs classification.
* **Request Payload**:
  ```json
  {
    "Age": 68.0,
    "BMI": 24.5,
    "BloodPressure": 120.0,
    "Cholesterol": 180.0,
    "MemoryComplaints": "Yes",
    "Confusion": "Yes",
    "Forgetfulness": "No"
  }
  ```
* **Response Payload**:
  ```json
  {
    "prediction": "High Risk",
    "confidence": 57.0
  }
  ```

## 7. Installation & Local Setup

### Prerequisites
- Python 3.11+
- Virtualenv/Conda (Recommended)
- Docker (Optional)

### Running Locally

#### 1. Setup Virtual Environment
Clone this project, navigate to the folder, create a virtual environment, and install libraries:
```bash
# Create and activate environment
python -m venv myenv
myenv\Scripts\activate      # Windows
source myenv/bin/activate   # macOS/Linux

# Install packages
pip install -r backend/requirements.txt
```

#### 2. Run ML Ingest & Model Training
Execute the pipeline locally to compile performance metrics and plots inside `outputs/`:
```bash
python -m backend.app.ml.alzheimers_pipeline
```

#### 3. Run the API Server
Launch the FastAPI ASGI application:
```bash
python -m backend.app.main
```
Open a browser and navigate to `http://127.0.0.1:5000/`. To test API endpoints interactively, visit the Swagger UI at `http://127.0.0.1:5000/docs`.

---

## 8. Running with Docker

Build and run the containerized application in the background:
```bash
# Build and boot services
docker compose build --no-cache
docker compose up -d
```
Access the application at `http://localhost:5000/`. To stop the container:
```bash
docker compose down
```
