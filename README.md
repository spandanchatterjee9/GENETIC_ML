# Alzheimer's Risk Predictor (GENETIC_ML)

AI-powered Alzheimer’s risk predictor using ML models with full evaluation metrics, Flask backend, and an interactive glassmorphism frontend for real-time medical risk prediction.

## Features
- **Machine Learning Integration**: Powered by a Random Forest algorithm predicting Alzheimer's risk.
- **Modern User Interface**: Responsive design with glassmorphism aesthetics.
- **RESTful API**: Flask backend that efficiently processes form data and performs predictions.

## Project Structure
- `app.py`: Main Flask server and REST endpoints.
- `alzheimers_pipeline.py`: Scripts for data preprocessing, training, and saving the machine learning model.
- `static/`: Contains static assets like `style.css` and `script.js`.
- `templates/`: Contains HTML files such as `index.html`.
- `*.pkl`: Serialized pre-trained Random Forest model and `StandardScaler` (generated by the pipeline - not included in source control).

## Setup & Execution

### 1. Installation

It is recommended to use a virtual environment. Install the necessary dependencies for the project:

```bash
pip install flask flask-cors pandas scikit-learn numpy 
```

### 2. Training the Model
If you are running the app for the first time, you will need the generated model (`rf_alzheimers_model.pkl`) and scaler (`scaler.pkl`). Since these are ignored in the repository, you must run the pipeline script to train the model and generate these files:

*(Ensure you have the `alzheimers_disease_data.csv` dataset in your root directory before running the pipeline)*

```bash
python alzheimers_pipeline.py
```

### 3. Starting the Server
Start the Flask application backend:

```bash
python app.py
```

### 4. Viewing the Application
Open a web browser and navigate to `http://localhost:5000/`. You can now input health metrics such as Age, BMI, Systolic BP, Total Cholesterol, and subjective memory/confusion complaints to receive an instant risk assessment.
